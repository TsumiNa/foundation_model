# Experiments index

One row per experiment folder: what it asked, what it found, where its data is. The folder's own `README.md` is the
lab notebook (design, execution log, full outcome); this table is the way in, for finding data again and for
analysis across experiments. Folder layout and the rules for this index: the `experiment-layout` skill
(`.claude/skills/experiment-layout/SKILL.md`). Add a row when an experiment starts; update it when the outcome is
known or the data moves.

This file is the only tracked file under `experiments/`; everything else travels by rsync. "Remote" paths:
RIKYU `$RIKYU_GROUP_DIR/fm/...` (the group-storage path; its value stays in local configuration), R-CCS the H200
workspace.
